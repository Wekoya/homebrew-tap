# Homebrew tap for Wekoya Code

```bash
brew install InnovateTechWorld/tap/wekoya
```

Then:

```bash
wekoya login     # sign in or create an account
wekoya           # start
```

AI pair programming, priced for African developers. Pay in naira from a wallet
or a plan, funded by bank transfer — no foreign card required.
